Easy Button — Field Data to Drawing

One guided path through the other tools. Load your code list once (code, description, our code) and save it as a profile; after that, any field file from your crews is translated to the standard codes and built into linework on the right layers, ready to edit in the Linework Editor — then written into your own template drawing with its layers and symbols, with pipe crossing tables where you draw boxes.

  1. Code list
  2. Field data
  3. Edit
  4. Template & drawing
  5. Pipe crossings

1 Code list

A CSV with three columns: code (what your crews type), description, and our code (the standard code it means) — plus, for pipes, optional size (inches), material (DI, C900 DR18, SDR35, RCP…) and class (ductile-iron pressure class). Leave "our code" blank to get a suggestion. ·

CodeDescriptionOur codeStatusSuggestions

2 Field data

A point file (P, N, E, Z, D) in your crew's codes — with a header, it may also carry a SIZE column (pipe size in inches per shot). Begin / end / close words, figure numbers and curve codes work as in the Linework Editor. On pipe shots, Z is the invert.

3 Edit

Open the linework in the Linework Editor to fix vertices and close figures — step 4 writes whatever is in the editor. For a Civil 3D survey database, download the linework script (figures named by our codes) and the figure prefix list to set up matching figure prefixes (layer from your template once matched). Point features (valves, hydrants, manholes…) are listed below; step 4 places them as your template's symbols.

4 Template & drawing

Upload your template drawing (an ASCII DXF with your layers and symbols). Each of our codes is matched to a template layer — and point codes to a symbol — by name; change any match below. The final DXF is your template with the survey drawn into it: its layers, styles and symbols stay as they are, pipes are 3D polylines that keep their inverts, and symbols get their attributes filled (point number, elevation / invert, description). Matches are saved with the profile.

5 Pipe crossings

Crossings are found where pipes cross in plan. At each one the pipe inverts are interpolated, the top and bottom of each pipe are worked out with the calculation below (by default: top = invert + inside diameter + wall, bottom = invert − wall, from published wall thicknesses — ductile iron or C900 PVC for water, PVC SDR 35 for sewer, RCP Wall B for storm), and the separation (upper pipe bottom − lower pipe top) is checked against the minimum. Drag a box on the plan around crossings that need a table — each box gets a crossing table in the JEA Pipe Crossing Table format, written into the DXF beside it (step 4's button, or the one below). Click a box to remove it; the mouse wheel zooms, a double-click shows the whole site. Pipe size comes from the shot (write it as 8IN — a bare 8 is a figure number, and a CSV point file drops the quote from 8"), else the code list's optional Size column, else the defaults here; with none, the crossing is "not scored".

    How your data is handled

    A drawing you open here is parsed, compared, auto-corrected and hashed in this browser tab — it is never uploaded. The app's own JavaScript can't send it anywhere either: the page's Content Security Policy (connect-src 'self') blocks every cross-origin request from the app's code. Everything the page needs — DOMPurify, the icon font and the web fonts — is served from this site, so no third-party host is contacted.
