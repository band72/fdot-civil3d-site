What's inside

Pick a workflow to see the tools

Every tool below is in the app today. Select a workflow for the tools that cover it.

QC & audit

CHECK
  • Easy ButtonLoad your code list once, then turn any crew's field file into linework on the right layers, ready to edit.
  • Standards Compare + Auto-CorrectCheck a DXF against the built-in FDOT 2026 layer standard, an uploaded standard or a master template, then write a corrected DXF.
  • DXF Project AuditorInspect a drawing's layers, entities and structure for problems before it goes out.
  • Traverse & COGO AuditorMisclosure, precision and bow-tie (self-intersection) checks on a traverse.
  • Legal Description QCParse a narrative description, plot the deed linework, close it and compute area.

Linework & basemap

EDIT
  • Linework EditorImport a point file or a bearing/distance call list, run field-data checks, then edit vertices and courses interactively. Civil 3D linework codes (B/C/E/CLS, arcs, circles, rectangles) are honored.
  • Basemap overlayTurn on an OpenStreetMap, Carto or USGS imagery / topo basemap behind the linework. Choose from 192 State Plane, UTM and provincial coordinate systems in meters or feet. Off by default.
  • Subdivision concept layoutDivide a boundary into lots with a cul-de-sac or through road and green space, adjust everything live, and export DXF or PDF.
  • EFB handbook toolsFDOT EFB point and reference naming, curve geometry and chain lists, feeding the editor.

Export & convert

DELIVER
  • DXF → Code FileTurn a DXF's lines, arcs, circles and polylines into a Civil 3D survey code file with numbered figures.
  • Linework exportsDXF, LandXML 1.2, CSV, P,N,E,Z,D text, a Civil 3D linework script, call lists and a Map Check report.
  • Parcel → DXF and reportsPlot parcels to DXF, and produce HTML / Markdown reports from the checks above.

Under the hood

Built around the numbers surveyors check

One shared geometry kernel, so every tool computes bearings, closures and areas the same way.

Coordinate systems

NAD83 State Plane for all 50 states, Puerto Rico and the Virgin Islands, Caribbean UTM, and Canadian UTM, MTM and provincial grids, in meters, US survey feet or international feet.

  • Transverse Mercator, Lambert, Albers, oblique Mercator
  • Checked against pyproj to within 5 mm

Field-data checks

Closure, snapping and self-intersection checks run as soon as data is imported, so problems surface before they reach the drawing.

  • Adjustable close and snap tolerances
  • Undo / redo on every edit

FDOT CADD standards

Layer, linetype and style checks against an FDOT standard, with safe auto-correction to a new DXF. The original is never overwritten.

  • Built-in, uploaded or template-based standards
  • Reference data is illustrative — verify before use

Private by design

Everything runs in your browser. Drawings and field files are not uploaded, and the page makes no third-party requests unless you turn the optional basemap on.

  • Strict content security policy
  • Fonts and icons are self-hosted
